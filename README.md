# Vampire Crawlers 出牌助手（VcAdvisor）

《Vampire Crawlers》的单机打牌辅助插件：**只读**读取游戏内存，实时给出本回合出牌顺序建议。
不修改任何游戏数值、不自动打牌、不改动游戏文件。

- 插件 GUID：`vampirecrawlers.advisor`
- 插件版本：`1.0.0`
- 形态：BepInEx 6（IL2CPP / x64）插件 + 独立置顶伴侣窗口（Win32 + GDI 自绘）

---

## 一、使用说明

### 1. 运行环境

| 项目 | 要求 |
|---|---|
| 游戏 | Vampire Crawlers（Steam AppID `3265700`，Unity IL2CPP x64） |
| 插件框架 | BepInEx `6.0.0-be` 系列（IL2CPP 版，x64） |
| 依赖 | 无额外依赖（`cards.tsv` 已内嵌进 DLL） |

### 2. 安装

1. 先按 BepInEx 官方说明为游戏安装 **BepInEx 6 IL2CPP x64** 版本并启动一次游戏，确认 `BepInEx/plugins` 已生成。
2. 退出游戏。
3. 将 `VcAdvisor.dll` 复制到：

   ```
   <游戏目录>/BepInEx/plugins/VcAdvisor.dll
   ```

4. 重新启动游戏。日志出现 `Vampire Crawlers 打牌助手 v1.0.0 已加载（只读模式，不修改任何游戏数值）` 即安装成功。

> 插件默认关闭了 BepInEx 的日志控制台窗口，避免启动时弹出多余的命令行窗口。

### 3. 伴侣窗口

游戏启动后，伴侣窗口会自动出现在**游戏窗口右侧**，并跟随游戏窗口移动、缩放；游戏最小化时它同步隐藏，还原时自动恢复。

窗口操作：

| 操作 | 效果 |
|---|---|
| 拖动标题栏 | 移动窗口（手动移动后不再自动贴靠游戏窗口） |
| 拖动右下角 | 调整窗口大小 |
| `F8` | 全局热键，显示 / 隐藏伴侣窗口 |
| `F9` | 把窗口强制拉到屏幕右下角并置顶（窗口跑到屏幕外时用来找回） |
| `进阶` / `简化` | 切换信息密度 |
| `收起` / `展开` | 收起为标题栏 |
| `×` | 隐藏窗口（`F8` 可再次显示） |

窗口为置顶、无边框、不在任务栏显示，且**不会抢占游戏焦点**，拖动和点击都不会让游戏失去激活。

### 4. 界面内容

**顶部状态**：回合数、当前连击数、法力；生命（含上限）、护甲、敌人数。

**出牌顺序**：按建议次序编号排列，每张牌显示

```
序号. 卡牌名  [角色类型 · 费用（回蓝）]  分值
```

- **进阶模式**最多显示 10 张牌及每张的评分理由；**简化模式**最多 6 张、不带理由。
- 连击进行中时，会额外提示「续连击需 N 费（递增 / 递减阶梯）」。
- 特殊卡牌标记：`★万能`（费用可当任意值）、`⚠开裂`、`✖已碎`。
- 生命偏低时会显示 `⚠` 预警；会攻击的敌人额外标 `⚔造成伤害`。

**敌人信息**：名称、生命 / 护甲、本回合意图与预计伤害。预计伤害会直接参与防御牌的优先级计算。

**牌库构成**：剩余牌的费用与角色分布（进阶模式显示更多）。

界面**不使用进度条或色条**表达数值，全部以文字与数字呈现。

### 5. 出牌逻辑

1. **连击优先**：先向游戏自身的 `IsCardInCombo` 询问手上哪些牌能接上当前连击；只要存在，首张就必须从中选择，避免断连击。
2. **连击阶梯**：之后按「上一张连击牌费用 ±1」逐张续接（`ReverseCombo` 时为递减）。阶梯值直接取自游戏的 `PreviousComboCardCost`。
3. **断连击时**：枚举所有可行的起始费用，模拟整段阶梯并取总分最高的一段。
4. **评分**：按卡牌角色（法力 / 武器 / 防御 / 经济 / 被动 / 功能 / 角色 / 负面）给出基础分，再结合生命比例、敌方预计伤害、敌人数量、法力余量、回蓝净消耗等局面因素修正。
5. **负面牌**：游戏类型为 `Debuff` 的牌基础分为 `-120`，不享受低费或 0 费加成，避免被推荐打出。
6. **费用**：以「配置基础费用 + 各项费用修正」计算当前实际费用，与官方 `CardDatabase.json` 一致。
7. **回蓝**：包括 `GainManaEffect`（固定回蓝）和 `GainManaEqualToCostEffect`（回复等于费用），净消耗 ≤ 0 的牌会获得额外权重。

### 6. 故障排查

日志文件：`<游戏目录>/BepInEx/LogOutput.log`

| 现象 | 处理 |
|---|---|
| 没有伴侣窗口 | 按 `F8`；或按 `F9` 强制拉到右下角（可能被移到屏幕外） |
| 窗口无内容 / 全黑 | 查看日志中的 `[窗口]` 与 `[绘制#N]` 行，确认 GDI 绘制是否报错 |
| 显示「未找到玩家对象」 | 正常：还没进入对战，进入一局后才会读取数据 |
| `F8` 无反应 | 热键可能被其他程序占用，日志会提示「全局热键 F8 注册失败」 |
| 卡名或费用异常 | 检查日志 `[计划]` 行与游戏是否更新过版本（游戏更新可能改变内部 API） |

## 二、构建说明

### 1. 环境准备

- .NET SDK 6.0 或更高（项目目标框架 `net6.0`）
- 已安装好 BepInEx 6 IL2CPP 的游戏目录（构建时需要引用其中的 `BepInEx/core` 与 `BepInEx/interop`）

### 2. 修改游戏路径

`VcAdvisor.csproj` 中的 `GameDir` 默认指向：

```xml
<GameDir>d:\Steam\steamapps\common\Vampire Crawlers</GameDir>
```

请改成你自己的游戏安装目录，或用命令行覆盖：

```powershell
dotnet build -c Release -p:GameDir="D:\你的路径\Vampire Crawlers"
```

### 3. 编译

```powershell
dotnet build -c Release
```

产物：

```
bin/Release/VcAdvisor.dll
```

`cards.tsv` 作为嵌入资源打包进 DLL，无需单独拷贝。

### 4. 部署

关闭游戏后覆盖：

```powershell
Copy-Item .\bin\Release\VcAdvisor.dll "<游戏目录>\BepInEx\plugins\VcAdvisor.dll" -Force
```

> DLL 在游戏运行时被锁定，无法覆盖，必须先退出游戏。

### 5. 项目文件说明

| 文件 | 作用 |
|---|---|
| `Plugin.cs` | BepInEx 入口、生命周期、伴侣窗口内容组装、后备的游戏内叠加层（`F7`） |
| `GameState.cs` | 只读采集游戏状态：玩家 / 敌人 / 手牌 / 费用 / 回蓝 / 连击 / 特殊卡 |
| `Scoring.cs` | 卡牌评分与本回合出牌计划编排 |
| `CardDb.cs` | 卡牌名称（调用游戏本地化接口）与角色分类 |
| `CompanionWindow.cs` | 独立置顶伴侣窗口：窗口消息、布局、GDI 绘制、热键、贴靠跟随 |
| `cards.tsv` | 内嵌的卡牌补充名称表（嵌入资源） |

## 三、说明与免责

- 本插件**只读**游戏内存，不写入任何游戏数据，不自动执行出牌。
- 仅用于单机模式的辅助参考，出牌建议不保证最优；请自行判断。
- 游戏版本更新后，内部类型与字段可能变化，届时需要重新核对 API。
